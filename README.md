# 一談多用：社工 AI 輔助工作台（Demo）

社安網 2.0 數位應用與服務匯流行動實驗的概念原型。社工維持原有的訪視與紀錄方式，系統接手整理、轉格式與統計：資料登錄一次，個案紀錄、轉介資料包、匯入檔、貼上版與月報都從同一份已確認的資料產出。

> 畫面中的單位、個案、人名與數字皆為**合成資料**，僅供示範。

## 如何開啟

- 直接用瀏覽器開啟 `index.html`（單一檔案，無需安裝）。
- 或在 repo 的 **Settings → Pages** 選擇 `main` 分支根目錄，即可用 GitHub Pages 線上瀏覽。

開啟後選擇身分：**社工**（王怡君）或 **督導**（陳督導）。右上角「切換身分」可回到選擇頁。

## 主要功能

**社工**
- 我的今天：今日行程、處理中佇列、待確認草稿、轉介回覆
- 收案匯入：自動去識別化，社工只確認沒把握的詞
- 開案訪視：訪後口述（約 1 分鐘，華台語混用）／訪談錄音（經同意）
- 個案狀況說明：信心分級、高信心一次確認、社工親填專業判斷、送督導審核
- 家系圖與服務紀錄：點家人看他在本會各方案的服務（依權限）
- 轉介：依對方格式產出資料包，經現行管道送出，追蹤回覆
- 匯入檔、貼上版與月報；訪視表單匯入；重複欄位地圖；跨方案查詢

**督導**
- 我的團隊今天、審核佇列（逐筆／例行批次核可）、派案建議
- 方案總覽、成果人次統計、人員比對與家戶連結、共享規則、稽核、基線量測

## 設計原則

- AI 只產出草稿，專業判斷（風險、需求等級、評估意見、兒少表意）由社工親填
- 送語言模型前先去識別化；保護性通報不送 AI、不跨方案
- 不介接、不回寫政府系統；不在機構間直接傳遞個案資料
- 數字由程式計算並可回溯原始紀錄

## 技術

單一 HTML 檔，原生 JavaScript，無建置步驟、無外部相依（字型取自 Google Fonts，離線時改用系統字型）。
